# Vibeathon-Multi-Factor-Proof-of-Life
This is a project which aims to implement multi factor proof of life authentication for users.

## Features
- One-attempt interaction challenge
- Time-bound human reaction validation
- Session-bound token
- Replay-resistant access
- Short-lived proof-of-life token
